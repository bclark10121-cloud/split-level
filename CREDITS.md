# Credits

Split Level is an original game. The house, the rooms, the doors and the room changes are built in code from data. No personal names here (G1.11).

## Music

- The start screen track is a stand-in made for the studio's starter game. Real music comes with the look and sound picks.

## Sounds

- The door latch, the door close and the menu sounds are made in code for this game (`tools/make_door_sfx.py` and the starter's sound tool).
